# 栗農家三代目が守りたい　秋に栗という文化と風景
### 筑西市・吉原農場　吉原壱さん

## P1　栗を買いに人が集まった頃（638字）

吉原農場の栗畑の向こうに、筑波山が見える。約七十年前、初代の吉原隆さんが山林を切り開き、五十本の苗木を植えた。今は三代目の吉原壱さんが、約千本の栗の木を育てている。吉原さんは「うちは栗専門なので、基本的には全部栗畑ですね」と言う。

吉原さんが子どもの頃、収穫の時期になると、農場には栗を買いに来る人がいた。作業を手伝いに来るパートさんもいた。吉原さんは当時を「栗を中心に人が集まってるようなイメージ」だったと振り返る。

継いだきっかけは、最初は家業だからだった。当時は父も現役で、木を受け継ぐ感覚はあまりなかったという。仕事を始めてみると、子どもの頃の記憶とはだいぶ違っていた。吉原さんは「昔はなんか、もっと賑わってたな」と感じた。

吉原農場の公式サイトによれば、茨城県は栗の生産高で日本一だ。吉原さんは「秋に栗って、たぶん皆さん思うじゃないですか」と問いかける。そして吉原さんは「それってもう、ほぼほぼ文化だと思うんですよね」と続ける。吉原さんは「このまま行ったら、これ無くなるかもしれない」と思い、「それは嫌だな」と感じた。家業ではあるが、生きていくには産業にしておかなければならない。そこから本気になった。

筑西市の明野地区には、かつて栗農家の組合があり、多くの農家が加わっていた。今は、その組合自体がなく、個人で続ける農家がいる。栗農家の数も、吉原さんの幼い頃からの約三十年で半分以下になった。吉原さんは地域の栗づくりを続いていける産業に育て、次の世代へ託したいと考えている。

## P2　むき栗から、栗の深雫へ（637字）

栗は安定しない作物だ。そのことを知る人は、どのくらいいるだろうか。吉原さんによれば、人によっては「博打でしょ」と言われるほどだという。吉原さんは「毎年、栗がいい年ってないんですよ」とも話す。だから、まず加工の道を探った。

最初に考えたのは、栗が手に取られない理由だ。吉原さんは「一番めんどくさいからですよね、皮むいたりが」と言う。栗が好きな人でも、うなずく理由ではないだろうか。最初の加工品は、むき栗だった。

吉原農場の栗には、もう一つの特徴がある。吉原さんの代から名乗る「熟成栗」だ。公式サイトによれば、熟成栗は収穫後の栗を氷温で約一か月寝かせ、甘さを引き出した栗だ。吉原農場では一か月以上、温度と湿度を管理している。吉原さんによれば、栗は温度の高い所に置くとデンプンを使い、甘さが抜けていく。一般の栗は、店に並ぶまで常温で少なくとも三日ほど動いているという。吉原さんは「うちの栗の場合は、もう常温に置いてる時間がめちゃくちゃ短い」と話す。

むき栗の次は、焼き栗だった。吉原さんは「熟成させないと、まあ全く美味しくないので」と言う。品種ごとに熟成を試し、自分で食べて比べた。

父の代は、生栗を栗きんとんの会社に卸していた。そこから、焼き栗で作る栗きんとん「栗の深雫」が生まれ、去年オンラインで売り出した。吉原さんは「変えられないものは変えられないけど、変えられるものはバカバカ変えてくので」と語る。原因を見極め、変化を恐れず挑戦するその決断力と実行力に、次代の栗農家の姿が見える。

## P3　朝露の栗畑を、次の代へ（440字）

栗は品種によって、味が全然違う。それを知る人は、あまりいない。だから吉原さんは、来てくれた客に「どうやって食べます？」と尋ねる。焼き栗に向くが、煮込むのには向かない栗もある。そうした違いを伝えるのは、吉原さんいわく「せっかく来てもらってるので」だ。客は、同じ年のうちや次の年に、また来てくれる。吉原さんが「あ、良かったんだな」と思うのは、そのときだという。

吉原さんは毎日、同じ畑を歩いて回る。一番好きな時間は、十月の頭の晴れた日の朝だ。落ちたての栗に朝露がつき、太陽を反射して光る。吉原さんは「一番最初にそこに行った人しか見れないので」と言う。畑の景色は、子どもの頃からそんなに変わっていない。カブトムシやクワガタも、ずっといる。吉原さんは「たぶん原風景なんですよね」と言い、「だから、それを残したいと思っているところもあって」と続ける。子や孫の世代まで、ここが栗畑であってほしいと話す。

秋に栗を思う文化と、朝露に光る栗畑の風景。栗農家の三代目が守ろうとしているのは、その二つだ。
