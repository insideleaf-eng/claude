# 栗は文化だから、栗農家を産業にする
### 筑西市・吉原農場 三代目 吉原壱さん

## P1　栗を買いに人が集まった頃（629字）

吉原農場の栗畑の向こうに、筑波山が見える。約七十年前、初代の吉原隆さんが山林を切り開き、五十本の苗木を植えた。今は三代目の吉原壱さんが、約千本の栗の木を育てている。壱さんは「うちは栗専門なので、基本的には全部栗畑ですね」と言う。

壱さんが子どもの頃、収穫の時期になると、農場には栗を買いに来る人がいた。作業を手伝いに来るパートさんもいた。壱さんは当時を「栗を中心に人が集まってるようなイメージ」だったと振り返る。

継いだきっかけは、最初は家業だからだった。当時は父も現役で、木を受け継ぐ感覚はあまりなかったという。仕事を始めてみると、子どもの頃の記憶とはだいぶ違っていた。壱さんは「昔はなんか、もっと賑わってたな」と感じた。

吉原農場の公式サイトによれば、茨城県は栗の生産高で日本一だ。壱さんは「秋に栗って、たぶん皆さん思うじゃないですか」と問いかける。そして壱さんは「それってもう、ほぼほぼ文化だと思うんですよね」と続ける。壱さんは「このまま行ったら、これ無くなるかもしれない」と思い、「それは嫌だな」と感じた。家業ではあるが、生きていくには産業にしておかなければならない。そこから本気になった。

筑西市の明野地区には、かつて栗農家の組合があり、多くの農家が加わっていた。今は、その組合自体がなく、個人で続ける農家がいる。栗農家の数も、壱さんの幼い頃からの約三十年で半分以下になった。壱さんは地域の栗づくりを続いていける産業に育て、次の世代へ託したいと考えている。

## P2　むき栗から、栗の深雫へ（638字）

壱さんは「産業にしないと残っていかないよね」と言う。だが栗は安定しない作物で、人によっては「博打でしょ」と言われる。続けていくために、壱さんは加工の道を探った。

最初に考えたのは、栗が手に取られない理由だ。壱さんは「一番めんどくさいからですよね、皮むいたりが」と言う。茹でれば四十分ほどかかる。最初の加工品は、父の代にはなかったむき栗だ。

自分の代からは、「熟成栗専門」と名乗るようになった。壱さんによれば、栗は温度の高い所に置くとデンプンを使い、甘さが抜けていく。一般の栗は、店に並ぶまでに常温で少なくとも三日ほど動いているという。公式サイトによれば、熟成栗は収穫後の栗を氷温で約一か月寝かせ、甘さを引き出した栗だ。吉原農場では一か月以上、温度と湿度を管理している。

熟成栗を始めた頃の悩みを、壱さんは「美味しいのを分かってもらいたいんだけど、でも手にとってもらえない」と話す。加工品で、一つずつ解決していった。むき栗の次は、焼き栗だった。壱さんは「熟成させないと、まあ全く美味しくないので」と言う。品種ごとに熟成を試し、自分で食べて比べた。

やがて焼き栗は、仕入れでも作れるため手がける人が増えた。そこで目を向けたのが、父の代に生栗を卸していた先の栗きんとんだ。県内に作る所は少なかった。味はいいが歩留まりの悪い品種も、ペーストなら全部むいて使える。焼き栗から作る「栗の深雫」は、去年オンラインで売り出した。壱さんは「これ細く長く、文化まで持っていったら、安定するかな」と考えた。

## P3　朝露の栗が残すもの（445字）

栗は品種によって、味が全然違う。それを知る人は、あまりいない。だから壱さんは、来てくれた客に「何やります？」と聞く。食べ方を聞いて、それに合う栗を勧める。壱さんは「渋皮煮はできない栗だよ、これ」と伝えることもある。壱さんによれば、客はその年のうちにも次の年にも、もう一度来てくれる。

壱さんは毎日、同じ畑を歩いて回る。一番好きな時間は、十月の頭の晴れた日の朝だ。壱さんは「誰も通ってないところにピッカピカの栗が落ちてて」と話す。落ちたての栗に朝露がつき、太陽を反射して光る。壱さんは「一番最初にそこに行った人しか見れないので」と言う。畑の景色は、子どもの頃からそんなに変わっていない。カブトムシやクワガタも、ずっといる。枯れた木は植え替えてきた。十年ほど前から急に暑くなり、合わなくなった品種を一斉に変えた。壱さんは、この場所の景色を「たぶん原風景なんですよね」と言う。願いは、子や孫の世代まで、ここが栗畑であることだ。壱さんは「美味しい栗があるよね、あそこには」と続いていってほしいと話す。
