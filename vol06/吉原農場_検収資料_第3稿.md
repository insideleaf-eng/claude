## 1. 依頼文の一文の扱い

依頼文：「かつて旧明野地区に数多くあった栗農家は、この三十年で半分以下に減ってしまった吉原さんは地域の栗栽培を持続可能な産業として育て、次の世代へしっかりと託していきたいと考えている」

| 依頼文の表現 | 本文での扱い | 理由 |
|---|---|---|
| 旧明野地区 | 「筑西市の明野地区」 | 資料Aの表現は「筑西市内の明野地区」（L43）。「旧」は資料A・Bにない |
| 数多くあった栗農家 | 「栗農家の組合があり、多くの農家が加わっていた」 | L43（約50軒。軒数は書かない指定なので「多くの」とした） |

| 減ってしまった | 「なった」 | 感情の色が付くため、事実だけを書いた |
| 吉原さん | 「壱さん」 | 記事全体の呼び方に合わせた。初代の吉原隆さんとも区別できる |
| 持続可能な産業 | 「続いていける産業」 | 本人の言葉「続いていけるようにしなくちゃいけない」（L231）に合わせた |

## 4. 未確定事項

1. **商品案内ページ**：参照URLを確認できていない。熟成栗の説明、深雫の原材料と製法、発売時期を、ページと照合すること。
2. 「壱」か「初」か、「栗の深雫」か「栗の雫」か（第1稿から引き続き）。
3. **「旧明野地区」**：使う場合は、行政上の表記を編集部で確認すること（資料A・Bにない）。
4. **「半分以下」の範囲**：全国・県・明野地区のどれの数字か、公式サイトで確認すること。
5. **「少なくとも三日」**：本人の推測を含む（L717「たぶん最低3日間ぐらい」）。本文では「という」と伝聞の形にした。
6. **書かないことのリストとの関係**：最初の指示書の「書かないこと」には「栗きんとんの経緯の細部」があった。今回は物語として深雫まで書く依頼のため、次の3点だけを使った。どこまで載せるかは編集部で判断すること。
   - 卸先が栗きんとんの会社だったこと
   - 県内に作る所が少なかったこと
   - ペーストなら全部むいて使えること

   西日本と東日本の違い、おせちの話、大量生産できない話は使っていない。

## 5. 第1稿からの変更ログ

1. **P1の締め**：依頼の一文を、資料に合わせて書き替えて置いた（表1）。
2. **P1の組み替え**：日本一、文化の話、「このまま行ったら」を第4段落にまとめた。第5段落は、明野地区、半減、託したい思いで締めた。
3. **P2の書き替え**：「産業にしないと」→ 栗は博打 → むき栗 → 熟成栗 → 焼き栗 → 栗の深雫、の順で、因果がつながる物語にした。
4. **普通の栗との違い**：本人の説明（温度が高いと甘さが抜ける。一般の栗は常温で数日動く）と、公式サイトの熟成栗の定義を並べた。その上で、吉原農場の管理（一か月以上、温度と湿度）で締めた。
5. **P2から外したもの**：シェフの「皮の裏」の話、「変えられないものは」「毎年、栗がいい年って」「やりようで」「どんな形でもいい」の引用。物語の線を一本にするため。
