# ご招待状テンプレート

オリジナルデザインの招待状ページです。単一の `index.html` にCSS・JavaScriptを含んでおり、ブラウザで開くだけで動きます。

## 使い方

1. `index.html` をテキストエディタで開き、先頭付近の `INVITATION` の内容を書き換えます。
   - 名前、日時、会場、住所、地図URL、出欠の連絡先、カウントダウンの日時（`target`）
2. 音楽を使う場合は `music` に音源のパスを指定します（例: `music/theme.mp3`）。音源は自分で用意したものを使ってください。
3. ブラウザで開いて確認します。

## 機能

- 封筒を開く開封演出（「OPEN」ボタンまたは「スキップ」で本文へ）
- 花びらの装飾アニメーション
- 日時のカウントダウン
- 任意の背景音楽（再生/停止ボタン）
- スマホ幅に対応したレイアウト
- ライト/ダークテーマ（OS設定に従う）
- 動きを減らす設定（`prefers-reduced-motion`）のユーザーには演出を省略

## 注意

- 既存サイトの画像・動画・フォント・コードはそのまま使っていません。レイアウトや雰囲気を参考にしたオリジナルです。
- 使用しているフォントは端末にあるフォント（明朝体）です。外部CDには接続しません。
