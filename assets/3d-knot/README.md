# 結び目ロゴの3Dデータ

添付ロゴの線をたどって作った3Dデータです。

| ファイル | 内容 |
|---|---|
| `knot.obj` | パイプ状の3Dメッシュ（OBJ形式）。外側の輪 `outer_loop`、内側の線 `inner_strand`、端の丸い栓 `end_cap_0/1` の4つの部品 |
| `knot-path.json` | 線の中心の座標（`A` = 外側の輪、`B` = 内側の線、`r` = パイプの半径）。Three.js などで自分で描くときに使えます |

- 単位は任意です（ロゴの横幅が約3.6）。
- 交差のところで「上、下」と交互に重ねて、線同士が突き抜けないようにしています。
- 内側の線の右の端は、外側の輪の下にもぐり込んでいます。
